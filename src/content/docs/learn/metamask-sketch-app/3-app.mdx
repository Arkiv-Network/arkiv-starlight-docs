## 3. Running the App

<Steps>

1. **Start the dev server:**

    ```bash
    npm run dev
    ```

    Vite starts a local server, usually at `http://localhost:5173`.

2. **Connect MetaMask.** Click "Connect MetaMask" in the app. MetaMask prompts you to switch to Cheesecake, or to add it if needed, then connects your account.

3. **Draw and save.** Draw on the canvas with your mouse, then click "Save". MetaMask asks you to approve the transaction that stores your sketch on Arkiv.

4. **View your gallery.** After the network includes the transaction, your sketch appears in the "Recent Sketches" panel on the left.

</Steps>

## Summary

You built a browser-based application with Web3 guarantees.

- You created a MetaMask wallet integration that connects users to Arkiv without exposing a private key.
- You built a p5.js drawing canvas and stored user-generated artwork as entities on Arkiv.
- You used `custom(window.ethereum)` as a transport for browser wallet signing. Server-side code uses `privateKeyToAccount()` instead.
- You used the query builder to filter entities by owner and attributes, and to show them in a gallery.
