Before you write code, install the tools in this section and set up the project structure.

## 1. Prerequisites

Make sure that you have these tools on your system:

- **Node.js**: version v20.6.0 or higher.
- **A text editor**: a code editor like VS Code works well.
- **Test GLM**: test GLM pays for gas on the Cheesecake testnet, the native gas token of Arkiv. The app prompts MetaMask to switch to Cheesecake, or to add it, automatically.

<Aside type="tip">
Cheesecake has no public faucet yet. Ask in the [Arkiv Discord](https://discord.gg/arkiv), and a team member sends you test GLM.
</Aside>

### Step 1: Imports and Chain Switching

First, import the SDK. Then write a helper function that switches MetaMask to the Cheesecake testnet. If MetaMask has not added the chain yet, the function adds it.

<Code
  code={`import { createPublicClient, createWalletClient } from "@arkiv-network/sdk";
import { cheesecake } from "@arkiv-network/sdk/chains";
import { custom, http } from "viem";
import "viem/window";

async function switchToCheesecakeChain() {
  if (!window.ethereum) {
    throw new Error("MetaMask not installed");
  }

  const chainIdHex = \`0x\${cheesecake.id.toString(16)}\`;

  try {
    await window.ethereum.request({
      method: "wallet_switchEthereumChain",
      params: [{ chainId: chainIdHex }],
    });
  } catch (error: unknown) {
    if (
      error &&
      typeof error === "object" &&
      "code" in error &&
      error.code === 4902
    ) {
      // Chain not added yet: add it
      await window.ethereum.request({
        method: "wallet_addEthereumChain",
        params: [
          {
            chainId: chainIdHex,
            chainName: cheesecake.name,
            nativeCurrency: cheesecake.nativeCurrency,
            rpcUrls: cheesecake.rpcUrls.default.http,
            // No blockExplorerUrls: Cheesecake has no public block explorer yet.
            // MetaMask makes this field optional, so leave it out.
          },
        ],
      });
    } else {
      throw error;
    }
  }
}`}
  lang="ts"
  title="src/wallet.ts"
/>

The `switchToCheesecakeChain` function first tries `wallet_switchEthereumChain`. If MetaMask returns error code `4902`, the chain does not exist yet. In that case, the function calls `wallet_addEthereumChain`. This call uses the chain details from the `cheesecake` object of the SDK.

### Step 3: Create Arkiv Clients

Finally, add the factory function that creates two clients: a public client to read data, and a wallet client to write data. Export this function so other modules can use it.

<Code
  code={`import { createPublicClient, createWalletClient } from "@arkiv-network/sdk";

            rpcUrls: cheesecake.rpcUrls.default.http,

export async function connectWallet() {
  if (!window.ethereum) {
    throw new Error("MetaMask not installed");
  }

  await switchToCheesecakeChain();

  const accounts = await window.ethereum.request({
    method: "eth_requestAccounts",
  });

  return accounts[0];
}

export function createArkivClients(account?: \`0x\${string}\`) {
  if (!window.ethereum) {
    throw new Error("MetaMask not installed");
  }

  const publicClient = createPublicClient({
    chain: cheesecake,
    transport: http(),
  });

  const walletClient = createWalletClient({
    chain: cheesecake,
    transport: custom(window.ethereum),
    account,
  });

  return { publicClient, walletClient };
}`}

Server-side code uses `privateKeyToAccount()` with a private key. Browser code uses `custom(window.ethereum)` as the transport instead. MetaMask handles all the signing.
