Before you write code, install the tools in this section and set up the project structure.

## 1. Prerequisites

Make sure that you have these tools on your system:

- **Node.js**: version 22 or higher. Version 24 is the current LTS release. This tutorial uses the `--env-file` flag to load environment variables.
- **A text editor**: a code editor like VS Code works well.
- **An Arkiv testnet private key.** To create entities (write data) on Arkiv, you need a wallet. This tutorial uses the public Tiramisu testnet, so no real funds are at risk.

If you do not have a private key, generate a new one with this command:

```bash
node -e "console.log('0x' + require('crypto').randomBytes(32).toString('hex'))"
```

Copy the output and save it in a safe place.

<Aside type="caution" title="Never share your private key">
Anyone who has your private key can control your funds and entities.
</Aside>

## 2. Project Setup

Now create the project directory and install the required libraries.

<Tabs syncKey="user-os">

<TabItem label="Linux / macOS" icon="terminal" >

Open your terminal and run these commands:

<Steps>

1. **Create and enter the project folder:**

    ```bash
    mkdir arkiv-dashboard
    cd arkiv-dashboard
    ```

2. **Initialize a Node.js project.** This command creates a `package.json` file.

    ```bash
    npm init -y
    npm pkg set type=module
    ```

3. **Install dependencies.** Install the Arkiv SDK for blockchain interaction and `axios` to fetch data from the CoinGecko API.

    ```bash
    npm install @arkiv-network/sdk viem axios
    ```

4. **Create project files.** You need a backend directory for the data-fetching script, and a frontend directory for the dashboard.

    ```bash
    mkdir backend frontend
    touch backend/index.js backend/.env
    touch frontend/index.html frontend/style.css frontend/script.js frontend/charts.js
    ```

5. **Add your private key.** Open the `backend/.env` file and add the private key that you generated earlier.

    ```bash
    # backend/.env
    PRIVATE_KEY=0xYOUR_PRIVATE_KEY_HERE
    ```

</Steps>

</TabItem>

<TabItem label="Windows">

Open PowerShell and run these commands:

<Steps>

1. **Create and enter the project folder:**

    ```sh
    mkdir arkiv-dashboard
    cd arkiv-dashboard
    ```

2. **Initialize a Node.js project.** This command creates a `package.json` file.

    ```sh
    npm init -y
    npm pkg set type=module
    ```

3. **Install dependencies.** Install the Arkiv SDK for blockchain interaction and `axios` to fetch data from the CoinGecko API.

    ```sh
    npm install @arkiv-network/sdk viem axios
    ```

4. **Create project files.** You need a backend directory for the data-fetching script, and a frontend directory for the dashboard.

    ```sh
    mkdir backend, frontend
    New-Item backend\index.js, backend\.env
    New-Item frontend\index.html, frontend\style.css, frontend\script.js, frontend\charts.js
    ```

5. **Add your private key.** Open the `backend/.env` file and add the private key that you generated earlier.

    ```bash
    # backend/.env
    PRIVATE_KEY=0xYOUR_PRIVATE_KEY_HERE
    ```

</Steps>
