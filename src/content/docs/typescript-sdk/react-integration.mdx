The Arkiv SDK works in the browser out of the box. This page covers the two most common React patterns:

1. **Reading data**: query entities with a public client, cached via TanStack Query
2. **Writing data**: sign transactions with the user's wallet via wagmi

<Aside type="tip">
The SDK has no official React hooks package at this version. These examples use the plain SDK with TanStack Query and wagmi. Most React apps already include both.
</Aside>

## Reading Data with TanStack Query

Use a public client for queries: no private key required, safe to run in the browser.

### Setup the Query Layer

First, define fetcher functions separate from hooks so they are reusable and testable:

```ts
// lib/arkiv-queries.ts
import { createPublicClient } from "@arkiv-network/sdk"
import { cheesecake } from "@arkiv-network/sdk/chains"
import { eq } from "@arkiv-network/sdk/query"
import { http } from "viem"

const PROJECT_ATTRIBUTE = { key: "project", value: "my-app" }

export const publicClient = createPublicClient({
  chain: cheesecake,
  transport: http(),
})

export async function fetchEntitiesByType<T>(
  entityType: string
): Promise<(T & { arkivEntityKey: string })[]> {
  const result = await publicClient
    .select({ key: true, payload: true })
    .where(
      eq(PROJECT_ATTRIBUTE.key, PROJECT_ATTRIBUTE.value),
      eq("entityType", entityType),
    )
    .limit(50)
    .fetch()

  return result.entities
    .map((entity) => {
      try {
        return { arkivEntityKey: entity.key, ...entity.toJson() }
      } catch {
        return null
      }
    })
    .filter((item): item is T & { arkivEntityKey: string } => item !== null)
}

export async function fetchEntityByKey<T>(entityKey: string): Promise<T> {
  const entity = await publicClient.getEntity(entityKey)
  return entity.toJson()
}
```

### Create Hooks

Wrap the fetchers with TanStack Query for caching, deduplication, and background refetching:

```bash
npm install @tanstack/react-query
```

```ts
// hooks/useArkivQuery.ts
import { useQuery } from "@tanstack/react-query"
import { fetchEntitiesByType, fetchEntityByKey } from "@/lib/arkiv-queries"

export function useArkivQuery<T>(entityType: string) {
  return useQuery<(T & { arkivEntityKey: string })[]>({
    queryKey: ["arkiv", "entities", entityType],
    queryFn: () => fetchEntitiesByType<T>(entityType),
  })
}

export function useArkivEntity<T>(entityKey: string | null) {
  return useQuery<T>({
    queryKey: ["arkiv", "entity", entityKey],
    queryFn: () => fetchEntityByKey<T>(entityKey!),
    enabled: !!entityKey,
  })
}
```

### Use in Components

```tsx
import { useArkivQuery } from "@/hooks/useArkivQuery"

interface Post {
  title: string
  content: string
}

function PostList() {
  const { data: posts, isLoading, error } = useArkivQuery<Post>("post")

  if (isLoading) return <p>Loading...</p>
  if (error) return <p>Error: {error.message}</p>

  return (
    <ul>
      {posts?.map((post) => (
        <li key={post.arkivEntityKey}>{post.title}</li>
      ))}
    </ul>
  )
}
```

<Aside>
Every Arkiv entity has a unique `entity.key`. The fetcher merges it as `arkivEntityKey` into each item: use this as your React key instead of array indices.
</Aside>

<Aside type="caution">
Avoid using `useEffect` + `useState` for data fetching. It does not handle caching, race conditions, deduplication, or background refetching. Always use a data-fetching library like TanStack Query or SWR.
</Aside>

## Writing Data with wagmi

If your project uses [wagmi](https://wagmi.sh) (or a wagmi-powered kit like RainbowKit or ConnectKit), you can derive an Arkiv wallet client directly from the wagmi wallet client. This avoids duplicate wallet connection logic.

### Derive an Arkiv Wallet Client

```tsx
import { useAccount, useWalletClient } from "wagmi"
import { createWalletClient as createArkivWalletClient } from "@arkiv-network/sdk"
import { cheesecake } from "@arkiv-network/sdk/chains"
import { custom } from "viem"

function useArkivWalletClient() {
  const { address } = useAccount()
  const { data: wagmiWalletClient } = useWalletClient()

  if (!wagmiWalletClient || !address) return null

  return createArkivWalletClient({
    chain: cheesecake,
    transport: custom(wagmiWalletClient.transport),
    account: address,
  })
}
```

Then use the returned client like any other Arkiv wallet client:

```tsx
import { jsonToPayload, ExpirationTime } from "@arkiv-network/sdk"

function CreatePostButton() {
  const arkivClient = useArkivWalletClient()

  async function handleCreate() {
    if (!arkivClient) return

    const { entityKey, txHash } = await arkivClient.createEntity({
      payload: jsonToPayload({ title: "My Post", content: "Hello!" }),
      contentType: "application/json",
      attributes: {
        project: "my-app",
        entityType: "post",
      },
      expires: ExpirationTime.fromDays(30),
    })

    console.log("Created:", entityKey, txHash)
  }

  return (
    <button onClick={handleCreate} disabled={!arkivClient}>
      Create Post
    </button>
  )
}
```

<Aside type="tip">
The `transport: custom(wagmiWalletClient.transport)` line is the key: it reuses the same wallet connection that wagmi already manages, so users do not see a second connect prompt.
</Aside>

### Add the Cheesecake Network to wagmi Config

Register the Arkiv Cheesecake testnet in your wagmi config so wallet switching works:

```ts
// wagmi.ts
import { http, createConfig } from "wagmi"
import { cheesecake } from "@arkiv-network/sdk/chains"

export const config = createConfig({
  chains: [cheesecake],
  transports: {
    [cheesecake.id]: http(),
  },
})
```

If your app supports multiple chains, add `cheesecake` alongside them:

```ts
import { mainnet } from "wagmi/chains"
import { cheesecake } from "@arkiv-network/sdk/chains"

export const config = createConfig({
  chains: [mainnet, cheesecake],
  transports: {
    [mainnet.id]: http(),
    [cheesecake.id]: http(),
  },
})
```

## Writing Data without wagmi

If you are not using wagmi, you can connect MetaMask directly:

```ts
import { createWalletClient } from "@arkiv-network/sdk"
import { cheesecake } from "@arkiv-network/sdk/chains"
import { custom } from "viem"

// Prompt MetaMask to add the network (no-op if it's already added)
await window.ethereum.request({
  method: "wallet_addEthereumChain",
  params: [{
    chainId: `0x${cheesecake.id.toString(16)}`,
    chainName: cheesecake.name,
    nativeCurrency: cheesecake.nativeCurrency,
    rpcUrls: cheesecake.rpcUrls.default.http,
    // No blockExplorerUrls: Cheesecake has no public explorer yet, and the field is optional.
  }],
})

// Connect
const [address] = await window.ethereum.request({
  method: "eth_requestAccounts",
})

const walletClient = createWalletClient({
  chain: cheesecake,
  transport: custom(window.ethereum),
})
```

For a complete browser example using this approach, see the [MetaMask Sketch App](/learn/metamask-sketch-app/) tutorial.
</Aside>
