Arkiv provides an official TypeScript/JavaScript SDK, [`@arkiv-network/sdk`](https://www.npmjs.com/package/@arkiv-network/sdk), that works in Node.js, Bun, and the browser. It handles client creation, queries, mutations, event watching, and payload encoding.

The SDK builds on [viem](https://viem.sh). It declares viem as a **peer dependency**. Install `viem` alongside the SDK.

## Install the SDK

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install @arkiv-network/sdk viem
    ```
  </TabItem>
  <TabItem label="Bun">
    ```bash
    bun add @arkiv-network/sdk viem
    ```
  </TabItem>
</Tabs>

## Client Setup

### WalletClient (read/write)

WalletClient needs a private key. Use it to create, patch, and delete entities:

```ts
import { createWalletClient } from "@arkiv-network/sdk"
import { tiramisu } from "@arkiv-network/sdk/chains"
import { http } from "viem"
import { privateKeyToAccount } from "viem/accounts"

const walletClient = createWalletClient({
  chain: tiramisu,
  transport: http(),
  account: privateKeyToAccount(process.env.PRIVATE_KEY as `0x${string}`),
})
```

<Aside type="caution">Keep your private key in environment variables. Do not hardcode it.</Aside>

### PublicClient (read-only)

PublicClient needs no private key. Use it for queries. It is safe for frontend use:

```ts
import { createPublicClient } from "@arkiv-network/sdk"
import { tiramisu } from "@arkiv-network/sdk/chains"
import { http } from "viem"

const publicClient = createPublicClient({
  chain: tiramisu,
  transport: http(),
})
```

## Hello, World!

<Steps>

1. **Create your project**

   <Tabs>
     <TabItem label="npm">
       ```bash
       mkdir hello-arkiv && cd hello-arkiv
       npm init -y
       npm pkg set type=module
       npm install @arkiv-network/sdk viem typescript
       ```
     </TabItem>
     <TabItem label="Bun">
       ```bash
       mkdir hello-arkiv && cd hello-arkiv
       bun init -y
       bun add @arkiv-network/sdk viem
       ```
     </TabItem>
   </Tabs>

2. **Add your private key**

   ```bash title=".env"
   PRIVATE_KEY=0xYOUR_PRIVATE_KEY_HERE
   ```

   Arkiv chains use GLM as the native gas token. Get test GLM from the [faucet](https://hub.arkiv.network/faucet).

3. **Write your first entity**

   ```ts title="hello.ts"
   import { createWalletClient, createPublicClient, ExpirationTime } from '@arkiv-network/sdk';
   import { stringToPayload } from '@arkiv-network/sdk/utils';
   import { tiramisu } from '@arkiv-network/sdk/chains';
   import { http } from 'viem';
   import { privateKeyToAccount } from 'viem/accounts';

   const walletClient = createWalletClient({
     chain: tiramisu,
     transport: http(),
     account: privateKeyToAccount(process.env.PRIVATE_KEY as `0x${string}`),
   });

   const publicClient = createPublicClient({
     chain: tiramisu,
     transport: http(),
   });

   // Create an entity
   const { entityKey, txHash } = await walletClient.createEntity({
     payload: stringToPayload('Hello, Arkiv!'),
     contentType: 'text/plain',
     attributes: { type: 'greeting' },
     expires: ExpirationTime.fromHours(1),
   });

   console.log('Entity created:', entityKey);
   console.log('Transaction:', txHash);

   // Read it back
   const entity = await publicClient.getEntity(entityKey);
   console.log('Retrieved:', entity.toText());
   ```

4. **Run it**

   Run it with:

   <Tabs>
     <TabItem label="npm">
       ```bash
       npx tsx --env-file=.env hello.ts
       ```
     </TabItem>
     <TabItem label="Bun">
       ```bash
       bun run hello.ts
       ```
     </TabItem>
   </Tabs>

</Steps>

<Aside type="tip">
Most real applications store JSON data. Use `jsonToPayload` instead of `stringToPayload` for structured data. See [Mutating Data](/typescript-sdk/mutating-data/#payload-helpers) for details.
</Aside>

<Aside>
Arkiv stores all entities in a shared database. Tag your data with a unique project attribute. Then your queries return only your app's entities. See [Best Practices](/typescript-sdk/best-practices/#1-always-use-a-project-attribute).
</Aside>

## Browser Usage (CDN)

For static HTML/JS pages without a bundler:

```js
import { createPublicClient } from 'https://esm.sh/@arkiv-network/sdk?target=es2022&bundle-deps'
import { eq } from 'https://esm.sh/@arkiv-network/sdk/query?target=es2022&bundle-deps'
import { tiramisu } from 'https://esm.sh/@arkiv-network/sdk/chains?target=es2022&bundle-deps'
import { http } from 'https://esm.sh/viem?target=es2022'
```
