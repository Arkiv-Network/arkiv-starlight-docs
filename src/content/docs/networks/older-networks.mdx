## Moving an old app forward

Entities don't carry over between networks. Testnet state isn't ported, so anything you wrote to one network stays on it.

From Tiramisu, these changes move an app to Rabdi:

- **Pass an access key.** `rabdi` is a function: call it as `rabdi({ accessKey })`. See [access keys](/start-here/access-keys/#use-a-key-with-the-sdk)
- **Drop `not` and `ne`.** Rabdi has no `NOT` or `!=`. List the values to keep instead, with [the conditions it supports](/querying/filter/#conditions)
- **Drop `atBlock`.** Rabdi doesn't keep past blocks, so every read is of the latest block
- **Page with `offset`.** Cursors, `next()`, `hasNextPage()` and `for await` are gone. Use `limit` and `offset`, or [page by key](/querying/paginate/#page-by-key)
- **Drop `fromBlock`.** A [watcher](/querying/watch-events/) only sees events from when it starts

From Braga or Kaolin, the SDK has breaking changes from v0.7. Pointing your app at the new chain is not enough on its own. Start from [your first entity](/start-here/first-entity/).
