## Moving an old app forward

Entities don't carry over between networks. Testnet state isn't ported, so anything you wrote to Kaolin stayed on Kaolin, and anything you wrote to Braga stayed on Braga.

The SDK API itself hasn't changed across any of these. When a new network opens, the only thing you swap is the chain you point at:

```ts
import { createWalletClient } from "@arkiv-network/sdk";
// swap this import for the new chain when it ships
import { braga } from "@arkiv-network/sdk/chains";
```

If you're using wagmi or viem directly, you'll also want to update the chain object's `id`, `rpcUrls`, `blockExplorers` and `nativeCurrency`.
